Product guide

EvidencePulse Documentation

Availability: Marketplace publication is pending. Installation instructions below apply only after the app has been approved and made available in the Atlassian Marketplace.

Requirements

  • A Jira Cloud site where EvidencePulse is installed.
  • Permission to view the relevant issues or project.
  • An active Marketplace license or evaluation for the future paid commercial app.

Issue readiness panel

  1. Open an issue in Jira Cloud.
  2. Open the EvidencePulse issue panel if your administrator has installed and enabled the app.
  3. Review the six readiness checks and any suggested next action.
  4. Use the Refresh action after changing Jira issue details.

Project overview

  1. Navigate to a Jira project with the installed EvidencePulse project page.
  2. Open the EvidencePulse project overview.
  3. Review Ready / Needs attention / Blocked counts and the most frequent missing checks.
  4. Open relevant issues in Jira to make corrections. EvidencePulse does not edit issues.

Six checks explained

  • Meaningful summary: Detects an issue summary that appears too generic or insufficient.
  • Assignee: Checks that ownership is assigned.
  • Due date: Checks for the Jira due-date field.
  • Acceptance criteria: Looks for an acceptance-criteria indication in issue content.
  • Evidence indicator: Checks for signs of attached or linked supporting material. Indicators are not independently verified proof.
  • Unresolved blocker: Checks whether the issue appears blocked by a recorded condition.

Sampling and limitations

The project page reviews up to 25 recently updated issues the current user can access. Jira search may be eventually consistent, and the overview can be a partial sample. Results are heuristics, not a guarantee of quality, security, compliance, test completion or release readiness.

Permissions and privacy

The app uses the read:jira-work scope and runs Jira reads under the current user's permissions. The current app does not provide write operations or external AI processing. See the Privacy Policy.

Troubleshooting

  • No project data: Confirm the project contains issues you can view and that the app is installed.
  • License required: Ask the Jira site administrator to activate a valid Marketplace subscription or evaluation.
  • Partial sample: The overview does not claim to inspect every issue in the project.
