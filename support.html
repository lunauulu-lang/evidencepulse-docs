EvidencePulse Support

Documentation, issue reporting and support for EvidencePulse for Jira Cloud.

Contact support

Email: hello@alaibek.com. This is the developer-approved custom-domain support mailbox. Do not email passwords, API tokens, sensitive Jira issue content, or payment information.

Product questions and non-sensitive bug reports

You can use the public EvidencePulse support tracker to report non-sensitive bugs and request documentation improvements. Please include the affected page, steps to reproduce, the expected result and the observed result.

Protect customer information. Do not post Jira issue content, credentials, access tokens, customer names, private URLs, logs containing personal data or security vulnerabilities in public GitHub issues. Report sensitive concerns privately at hello@alaibek.com, without attaching credentials or confidential customer data.

Support availability

EvidencePulse is being prepared for a paid Atlassian Marketplace release. Support is available by email, but no response-time SLA or fixed customer support hours are promised at this stage. Atlassian emergency contact requirements are handled separately by the Marketplace Partner.

Current status

The public Marketplace listing has not yet been approved or published. Documentation here describes the planned commercial release based on an existing tested Forge application.
