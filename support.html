EvidencePulse Support

Documentation, issue reporting and support for EvidencePulse for Jira Cloud.

Product questions and non-sensitive bug reports

You can use the public EvidencePulse support tracker to report non-sensitive bugs and request documentation improvements. Please include the affected page, steps to reproduce, the expected result and the observed result.

Protect customer information. Do not post Jira issue content, credentials, access tokens, customer names, private URLs, logs containing personal data or security vulnerabilities in public GitHub issues. For sensitive reports, contact the developer through the developer GitHub profile until a dedicated private support channel is published.
