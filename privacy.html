EvidencePulse Privacy Policy

Last updated: November 13, 2026

Scope

EvidencePulse is a read-only Atlassian Forge application for Jira Cloud. It provides issue-level readiness checks and a project overview. This policy describes data the application accesses and how its own application code processes that data.

Data accessed

When an authorized Jira user opens EvidencePulse, the app requests issue data that user is permitted to access: issue key, summary, assignee, due date, description, status, labels and attachment metadata. The project overview requests a sample of up to 25 recently updated issues visible to that user.

Purpose and processing

These fields are used to compute six deterministic readiness hints: meaningful summary, owner, due date, acceptance criteria, supporting evidence indicator, and unresolved blocker. The app displays the results within Jira. It requests data through the Forge bridge using the Jira API as the current user; its declared Jira scope is read:jira-work. It does not modify Jira issues.

Storage and transfers

The current EvidencePulse application does not operate its own database, use Forge persistent storage, or intentionally retain copies of Jira issue data outside the user's Jira session. Its application code does not transmit issue content to an external AI provider, advertising provider, analytics service, or other third-party endpoint.

Jira and Forge are operated by Atlassian. Atlassian may process requests, browser traffic and operational logs under its own terms and privacy notices. This policy does not change Atlassian's data handling or a Jira administrator's settings.

Access and control

A signed-in user's Jira permissions control what the application can read. A Jira administrator can stop the app's access by uninstalling it. The app does not provide its own customer-data database or export function.

Questions and changes

For privacy questions, see the support page. If the application's data practices change, this policy will be updated before or alongside the corresponding release.
